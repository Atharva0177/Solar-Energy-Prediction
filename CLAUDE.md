# Solar_gemini project instructions

At session start in this repository, read `MEMORY.md` and the files it links
under `memories/` — they hold phase progress, workflow rules, and environment
gotchas. Keep them updated as work proceeds:

- After each completed PRD phase: update `TASKS.md`, `DECISIONS.md` (new
  decisions), `RESULTS.md` (measured numbers only), then refresh
  `memories/project-state.md`.
- Summarize the completed phase to the user and ask for confirmation before
  starting the next phase.
- `TASKS.md`, `DECISIONS.md`, `RESULTS.md` are authoritative; memory is a
  convenience snapshot.
